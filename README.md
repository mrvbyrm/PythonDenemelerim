# PythonDenemelerim

[![Python](https://img.shields.io/badge/Python-3.x-3776AB?style=flat-square&logo=python&logoColor=white)]()
[![Jupyter](https://img.shields.io/badge/Jupyter-Notebook-F37626?style=flat-square&logo=jupyter&logoColor=white)]()

Python öğrenme sürecimde yazdığım küçük alıştırma script'lerinin ve çözümlerin bir arada tutulduğu repo.

## Proje Hakkında

Bu repo tek bir uygulama değil; temel programlama kavramlarını (döngüler, fonksiyonlar, sınıflar, sayı algoritmaları vb.) pekiştirmek için yazılmış bağımsız Python dosyalarından oluşan bir koleksiyondur.

## İçerik

Öne çıkan bazı alıştırmalar:

| Dosya | Konu |
|---|---|
| `Fibonacci_Serisi.py` | Fibonacci serisi üretimi |
| `Armstrong_Sayısı.py` | Armstrong sayısı kontrolü |
| `AsalSayı.py` | Asal sayı kontrolü |
| `MükemmelSayı.py` | Mükemmel sayı algoritması |
| `HesapMakinesi.py` | Basit hesap makinesi |
| `atm_program.py` | Basit ATM simülasyonu |
| `KullanıcıGirişi.py`, `gelişmişKullanıcıGirişi.py` | Kullanıcı giriş/doğrulama alıştırmaları |
| `sayıTahminOyunu.py` | Sayı tahmin oyunu |
| `Python Notebook.ipynb` | Jupyter Notebook üzerinde çalışmalar |

## Kullanılan Teknolojiler

- Python 3
- Jupyter Notebook

## Kurulum ve Çalıştırma

```bash
git clone https://github.com/mrvbyrm/PythonDenemelerim.git
cd PythonDenemelerim/PythonDenemelerim
python <dosya_adı>.py
```

Notebook için:

```bash
jupyter notebook "Python Notebook.ipynb"
```
